# 经验文件格式规范（单文件版）

所有经验集中存放在 `experiences/lessons.md`，结构：文件头说明 → 目录表（脚本生成）→ 分区章节 → 条目。

## 分区（二级标题 `##`）

```
## 通用 · 技能开发      （agent-skill-dev：技能安装/检索/组装/嵌入）
## 通用 · Shell 工具    （shell-tooling：curl/wget/系统命令）
## 通用 · 网页抓取      （web-scraping：SPA/接口发现/抓取）
## 通用 · ima 集成      （ima-integration：OpenAPI/上传/COS）
## 专用 · 本项目        （dev-lessons 技能开发专用约定）
```

- **通用**：剥离项目上下文仍成立的解法，按项目类型分区。新增类型：当某类经验≥2条且现有分区放不下时，加 `## 通用 · <类型名>` 并在类型名后括注英文标识。
- **专用**：依赖本项目特有事物（路径约定、凭证位置、用户偏好、项目决策）。

## 条目（三级标题 `###`）

```markdown
### GEN-XXX-001 · 标题一句话（症状 → 解法关键词）

**问题**：现象描述，1-2 句。
**原因**：根因，1-2 句。
**解决**：可操作步骤/命令，紧凑列出。
**验证**：一行（日期 + 场景 + 结果）；未验证的写"待验证"。
```

- **问题/原因/解决三要素必填**，验证可选。总长控制在 10 行内，禁止写成文档。
- ID 规则：通用 `GEN-<类型缩写>-<三位序号>`（AGEN/SHEL/WEB/IMAI…），专用 `PRJ-<三位序号>`；ID 终身不变，更新条目不改 ID。

## 目录表（文件头，`lessons.py toc` 生成，禁止手编）

```markdown
## 目录

| ID | 分区 | 标题 | 状态 |
|---|---|---|---|
| GEN-AGEN-001 | 通用·技能开发 | curl -o 目录不存在时静默失败 | 正式 |
```

- 状态：`正式` / `draft`（draft = 待用户确认转正，条目标题行尾加 `（draft）`）。
- 目录表必须紧跟在文件头说明之后、第一个分区章节之前；`toc` 命令原位重建。
